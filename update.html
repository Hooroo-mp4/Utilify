How to update

  1. Download the new version with the button below and unzip it.
  2. Copy the new files over the folder you loaded RSI Utilify from (replace the old ones).
  3. Open your browser's extensions page and press the reload icon on RSI Utilify.
  4. Refresh any open RSI tabs.
Download View on GitHub

RSI Utilify checks GitHub for updates when your browser starts. You can switch this off in the extension menu.
